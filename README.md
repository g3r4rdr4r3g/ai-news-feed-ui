# Briefing

A responsive, static news-summary page. Story data lives in `summaries.json`; update that file to publish a new edition.

## GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch and `/ (root)`, then save.

GitHub Pages will publish `index.html` and `summaries.json` together. The page uses no build step or server-side code.
